# Mini-Project-9
♻️ Smart Waste Classification Using CNN

A deep learning-based web application that uses Convolutional Neural Networks (CNN) to classify waste images into organic and recyclable categories. Built using Python, TensorFlow, Keras, and Streamlit, it allows users to upload waste images and receive predicted categories along with confidence scores.

Technologies: Python, CNN, TensorFlow, Keras, NumPy, Streamlit, PIL.
